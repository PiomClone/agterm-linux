### Linux adaptations

- Track exact upstream v0.40.0, including per-pane message bus, markdown and image overlays, session info lines, sidebar icon toggles, and companion groups.
- Markdown files clicked in terminal output (or opened via `agtermctl session overlay open --markdown`) render with syntax-highlighted code blocks, task lists, and heading anchors over the session using WebKitGTK and bundled offline assets (`markdown-it`, `highlight.js`).
- Image files clicked in terminal output (or opened via `agtermctl session overlay open --image`) render centered over the session sized to image aspect ratio using GdkPixbuf.
- Session info line (`agtermctl session info TEXT`) renders under sidebar rows with Pango markup support and auto-hide timer backed by the GLib main loop.
- Interface settings to toggle workspace and session icons (`workspaceIcons`, `sessionIcons`) in sidebar rows with reactive snapshot layout.
- Per-pane message bus (`agtermctl msg send`, `msg read`, `msg ack`) routes through control server and dispatcher.
- Attach remote sessions with companions (`zmx attach --companions`) and remote companion group tracking.
